Apakah syarat kelayakan untuk memohon?

Program Satu Fasa terbuka kepada warganegara Malaysia berumur 15–45 tahun. Program Tiga Fasa memerlukan SKM Tahap 2 dalam bidang elektrikal dan umur 16–35 tahun. Lihat butiran program untuk syarat tambahan.

Adakah saya memerlukan pengalaman dalam elektrik?

Program Satu Fasa sesuai untuk mereka yang ingin membina asas kemahiran elektrik. Anda perlu boleh membaca, menulis dan mengira. Program Tiga Fasa memerlukan kelayakan SKM Tahap 2.

Berapa lama tempoh pengajian?

Tempoh bergantung pada program dan pengambilan. Hubungi penyelaras untuk pengesahan tempoh terkini sebelum memohon.
